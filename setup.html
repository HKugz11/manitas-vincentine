Site setup
1. Make a GitHub key (only you do this, once)
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick this site's repo.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Pick the longest expiration it allows. When it expires, just do this page again.
2. Lock the key with Nubia's password

The key is encrypted in your browser with the password and saved as lock.json. The password is never saved anywhere.
